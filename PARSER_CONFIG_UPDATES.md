# Обновления конфигураций парсеров

## Дата обновления: 2026-01-28

### 1. Аметист - Email конфигурация

**Тип парсинга:** Email (Excel в zip архиве)

**Настройки email:**
- **От:** `noreply@ametist.ru`
- **Тема письма:** `Остатки номенклатуры на складе 'ООО Аметист'`
- **Вложение:** ZIP архив
- **Внутри архива:** Excel файл

**Настройка через API:**
```json
POST /api/suppliers/{supplierId}/email-config
{
  "emailConfig": {
    "host": "imap.mail.ru", // или другой IMAP сервер
    "port": 993,
    "secure": true,
    "user": "your-email@example.com",
    "password": "your-password",
    "fromEmail": "noreply@ametist.ru",
    "subjectFilter": "Остатки номенклатуры на складе 'ООО Аметист'",
    "searchUnreadOnly": false,
    "searchDays": 90
  }
}
```

**Примечание:** Парсер автоматически распаковывает ZIP архив и находит Excel файл внутри.

### 2. Артекс - Обновлен URL формат

**Старый формат:** `https://artextkani.ru/wp-content/uploads/DD.MM.YYYY-2.xlsx`

**Новый формат:** `https://artextkani.ru/wp-content/uploads/YYYY/MM/DD.MM.YYYY-1.xlsx`

**Пример:** `https://artextkani.ru/wp-content/uploads/2026/01/28.01.2026-1.xlsx`

**Переменные части:**
- `YYYY` - полный год (2026)
- `MM` - месяц (01, 02, ..., 12)
- `DD.MM.YYYY` - дата в формате день.месяц.год (28.01.2026)
- Суффикс файла изменен с `-2.xlsx` на `-1.xlsx`

**Обновлено:**
- `lib/parsers/arteks-parser.ts` - добавлена поддержка нового формата URL с папками
- Все места инициализации поставщиков обновлены

### 4. Эгида - Обновлен формат даты в URL

**Старый формат:** `DD.MM.YY` (2-значный год)

**Новый формат:** `DD.MM.YYYY` (полный год)

**Пример:** 
- Старый: `26.01.26_ostatki_tkani_ooo_egida.xls`
- Новый: `26.01.2026_ostatki_tkani_ooo_egida.xls`

**URL:** `https://exch.tendence.ru/download.php?file=26.01.2026_ostatki_tkani_ooo_egida.xls`

**Обновлено:**
- `lib/parsers/egida-parser.ts` - метод `formatDateForUrl` теперь использует полный год

## Действия для восстановления работы

### Для Аметиста и Нортекса:
1. Настроить email конфигурацию через API endpoint `/api/suppliers/{id}/email-config`
2. Убедиться, что email аккаунт имеет доступ к входящим письмам
3. Запустить парсинг через `/api/suppliers/{id}/parse-email`

### Для Артекса и Эгида:
1. Парсеры автоматически обновлены
2. При следующем парсинге будут использоваться новые форматы URL
3. Парсеры автоматически найдут актуальный файл, перебирая даты

### Для Tex.Group и TextileNova:
1. Запустить анализ структуры через `/api/suppliers/{id}/analyze`
2. Проверить, изменилась ли структура данных
3. При необходимости обновить правила парсинга
