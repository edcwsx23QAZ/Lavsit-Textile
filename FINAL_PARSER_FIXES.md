## Улучшения логики

### 1. Автоматический fallback для email поиска

Если письма не найдены с фильтрами (fromEmail, subjectFilter), система автоматически:
1. Пробует поиск без фильтров (только по дате)
2. Фильтрует найденные письма вручную по fromEmail и subjectFilter
3. Это позволяет найти письма даже если IMAP фильтры работают некорректно

### 2. Использование файлов на диске

Если файлы есть в базе данных, но не найдены через стандартный метод:
1. Проверяет существование файлов на диске напрямую
2. Использует последний существующий файл для парсинга
3. Это позволяет повторно парсить уже обработанные файлы

### 3. Улучшенная обработка ошибок для Артекса

Парсер Артекса теперь:
- Продолжает поиск при временных ошибках (timeout, network errors)
- Логирует детальную информацию о каждой попытке
- Увеличено время ожидания до 15 секунд
