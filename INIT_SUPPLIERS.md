# Инициализация поставщиков

## ✅ Что сделано

1. **Создан API endpoint** для инициализации поставщиков: `/api/suppliers/init`
2. **Обновлен GET `/api/suppliers`** - теперь автоматически инициализирует всех поставщиков, если их нет или только один
3. **Скрипт инициализации** выполнен локально - все поставщики созданы в локальной БД

## 🚀 Инициализация на Production (Vercel)

### Способ 1: Автоматическая инициализация (рекомендуется)

Просто откройте страницу поставщиков - они автоматически инициализируются:

```
https://lavsit-textile.vercel.app/suppliers
```

Или вызовите API endpoint:
```
https://lavsit-textile.vercel.app/api/suppliers
```

API автоматически проверит количество поставщиков и инициализирует всех, если их нет или только один.

### Способ 2: Ручная инициализация через API

Вызовите POST endpoint для инициализации:

```bash
curl -X POST https://lavsit-textile.vercel.app/api/suppliers/init
```

Или откройте в браузере (POST запрос):
- Используйте Postman, Insomnia или другой HTTP клиент
- Или используйте браузер с расширением для POST запросов

## 🔧 Локальная инициализация

Если нужно инициализировать локально:

```bash
npm run db:init
```

Это создаст/обновит всех поставщиков в локальной базе данных.

## 📝 Примечания

- Инициализация использует `upsert` - если поставщик уже существует, он будет обновлен
- Если поставщик не существует, он будет создан
- Все поставщики создаются со статусом `active`
- URL парсинга и метод парсинга настраиваются автоматически
