# Исправления парсера TextileNova

## Дата: 2026-01-29

## Выполненные исправления

### 1. Улучшена обработка статусов в столбце B
- **"+"** → статус "в наличии"
- **"Ограничено"** → статус "в наличии" с комментарием "ВНИМАНИЕ, МАЛО!"
- **"НЕТ"** → статус "нет в наличии"
- Неизвестные статусы пропускаются

### 2. Улучшен парсинг дат из столбца C
- Поддержка формата DD/MM/YY (например, "20/02/26")
- Корректная обработка 2-значных годов (26 → 2026)
- Поддержка Excel серийных номеров дат

### 3. Исправлена логика формирования названий коллекций
- Полные названия (например, "Helena 07") не дополняются текущей коллекцией
- Только неполные названия дополняются текущей коллекцией

### 4. Фильтрация строк
- Обрабатываются только строки с данными в столбцах A и B
- Строки без данных в столбце B пропускаются

### 5. Оптимизация для Vercel
- Добавлена автоматическая детекция окружения Vercel
- Оптимизированы настройки Puppeteer для работы на Vercel:
  - `--single-process` для serverless функций
  - Увеличен timeout до 60 секунд на Vercel
  - Добавлены дополнительные флаги для оптимизации производительности
- Логика парсера работает одинаково на локальной машине и на Vercel

## Настройки таймаутов

- **Vercel maxDuration**: 300 секунд (5 минут) - настроено в `vercel.json`
- **Puppeteer launch timeout**: 60 секунд на Vercel, 30 секунд локально
- **page.goto timeout**: 30 секунд
- **axios timeout**: 30 секунд
