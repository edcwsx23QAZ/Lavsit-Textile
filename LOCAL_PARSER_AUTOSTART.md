# Автозапуск локального сервера парсеров

## Быстрый старт

### 1. Настройка автозапуска (один раз)

Запустите PowerShell от имени администратора и выполните:

```powershell
cd "E:\Work programs\cursor\repositary\lavsit-textile"
npm run local-parser:setup
```

Это создаст задачу в Планировщике задач Windows, которая будет автоматически запускать сервер и туннель при входе в систему.

### 2. Ручной запуск (если нужно запустить сейчас)

```powershell
npm run local-parser:start
```

Это откроет два окна:
- Окно с локальным сервером парсеров
- Окно с localtunnel (туннелем)

### 3. Получение URL туннеля

После запуска localtunnel покажет URL в своем окне. Он будет выглядеть примерно так:
```
https://xxxx-xxxx-xxxx.loca.lt
```

### 4. Настройка Vercel

1. Откройте Vercel Dashboard: https://vercel.com/dashboard
2. Выберите проект `lavsit-textile`
3. Перейдите в Settings → Environment Variables
4. Добавьте новую переменную:
   - **Name**: `LOCAL_PARSER_URL`
   - **Value**: URL из окна localtunnel (например, `https://xxxx-xxxx-xxxx.loca.lt`)
   - **Environment**: Production, Preview, Development (отметьте все)
5. Сохраните и перезапустите деплой

## Как это работает

1. При загрузке Windows автоматически запускается:
   - Локальный сервер парсеров на порту 4002
   - Localtunnel для создания туннеля

2. При ошибке парсинга на Vercel:
   - Система автоматически проверяет доступность локального сервера
   - Если доступен - отправляет запрос на локальный сервер
   - Если локальный сервер тоже не сработал - возвращает ошибку

## Управление автозапуском

### Проверить статус задачи

```powershell
Get-ScheduledTask -TaskName "LavsitTextileLocalParser"
```

### Удалить автозапуск

```powershell
Unregister-ScheduledTask -TaskName "LavsitTextileLocalParser" -Confirm:$false
```

### Остановить сервер вручную

Закройте окна PowerShell, которые были открыты при запуске.

## Устранение неполадок

### Сервер не запускается

- Проверьте, что порт 4002 не занят другим процессом
- Убедитесь, что все зависимости установлены: `npm install`
- Проверьте логи в окне сервера

### Туннель не создается

- Убедитесь, что есть интернет-соединение
- Проверьте, что localtunnel может подключиться к серверу
- Попробуйте запустить вручную: `npx localtunnel --port 4002`

### Vercel не может подключиться

- Убедитесь, что переменная `LOCAL_PARSER_URL` правильно настроена в Vercel
- Проверьте, что туннель активен (окно localtunnel должно быть открыто)
- Убедитесь, что URL использует HTTPS
- Проверьте health check: откройте в браузере `https://your-tunnel-url.loca.lt/health`

## Альтернатива: ngrok

Если у вас установлен ngrok, вы можете использовать его вместо localtunnel:

1. Установите ngrok: https://ngrok.com/download
2. Запустите: `ngrok http 4002`
3. Скопируйте HTTPS URL из интерфейса ngrok
4. Добавьте его в `LOCAL_PARSER_URL` в Vercel

Ngrok предоставляет более стабильные URL, но требует регистрации для постоянного использования.
